Logistic Regression

Logistic regression is a supervised machine learning algorithm used for classification problems. Unlike linear regression, which predicts
continuous values, logistic regression predicts the probability that na input belongs to a specific class. Like binary classification,
where outputs can be one of two possible categories like Yes/No, True/False, or 0/1. This is done but using a sigmoid function to convert
inputs into a probability value between 0 and 1.

Types of Logistic Regression:
    1. Binomial Logistic Regression
        - This is used when the dependent variable has only two possible categories. Like Yes/No, True/False, or 0/1.
        - This is the most common type of logistic regression and is used for binary classification problems.
    2. Multinomial Logistic Regression
        - Used when there are three or more possible categories that are not ordered. Such as classifying types of animals into categories.
        - This extends the binary logistic regression to handle multiple classes.
    3. Ordinal Logistic Regression
        - Applied when the dependent variable has three or more categories with a natural order of ranking. Such as "low", "medium", and "high".
        - The order of the categories is taken into account when modeling.
